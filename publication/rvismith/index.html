RVISmith: Fuzzing Compilers for RVV Intrinsics

Yibo He, Cunjian Huang, Xianmiao Qu, Hongdeng Chen, Wei Yang, Tao Xie

In CCS

PdfDataset

Summary

RVISmith is a randomized compiler fuzzer that generates well-defined C programs containing RISC-V vector intrinsic sequences. It aims to improve intrinsic coverage and sequence diversity while avoiding undefined behavior. Evaluation on GCC, LLVM, and XuanTie reports 11.5 times greater intrinsic coverage than a prior fuzzer and 13 confirmed, previously unknown compiler bugs.

TAOPT: Tool-Agnostic Optimization of Parallelized Automated Mobile UI Testing

Dezhi Ran, Zihe Song, Wenyu Wang, Wei Yang, Tao Xie

In ASPLOS

Summary

TaOPT improves parallel mobile UI testing without changing the underlying testing tools. It infers loosely coupled UI subspaces and coordinates testing devices to explore different subspaces. Experiments with three Android testing tools report comparable coverage with 60% less testing duration and 62% less machine time, together with more unique crashes under the same resource budget.
